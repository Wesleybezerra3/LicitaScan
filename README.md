# LicitaScan

Automação para busca e coleta de editais em portais de licitações.

## 🎯 Objetivo

O **LicitaScan** tem como objetivo automatizar o processo de pesquisa de editais que atualmente é realizado manualmente.

A aplicação acessa diferentes portais de licitações, realiza buscas utilizando palavras-chave, identifica editais relacionados e coleta suas principais informações.

Futuramente, o projeto poderá evoluir para uma central de licitações, com recursos como:

- Busca em múltiplos portais;
- Download automático de editais e anexos;
- Filtros e classificação de oportunidades;
- Histórico de editais encontrados;
- Notificações;
- Análise automatizada utilizando IA.

## 🛠️ Stack atual

- **Node.js** — ambiente de execução;
- **JavaScript** — linguagem principal;
- **Playwright** — automação e navegação nos portais;
- **JSON** — armazenamento inicial dos dados coletados;
- **File System (Node.js)** — gerenciamento dos arquivos e diretórios.

## 📌 Status

**Em desenvolvimento.**

Atualmente, o projeto está sendo desenvolvido inicialmente para automatizar a coleta de editais em um portal, servindo como base para posteriormente adicionar outros portais e funcionalidades.
